## New in 1.53.4: open a plan by double-clicking it

For the Windows app installed with the Setup file:

- **Double-click a .mimar file to open it in MIMAR.** Plan files now show the MIMAR icon in Explorer and are listed as "MIMAR plan". If the plan you have open has unsaved changes, MIMAR asks whether to save them first, as it does for File > Open. Save then writes back to the file you double-clicked.
- **One MIMAR at a time.** Starting MIMAR again, or double-clicking another plan while it is open, brings the open window forward (and opens that plan in it) instead of starting a second copy. Two copies used to share one autosave, so the one closed last would win.

The file type is registered when this update installs. The portable app opens a plan dragged onto its .exe the same way, but does not register the file type.
