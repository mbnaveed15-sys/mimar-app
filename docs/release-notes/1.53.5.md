## New in 1.53.5: a connector for AI agents

MIMAR can now be used by an AI agent such as Claude, through a connector (an MCP server) that comes with the installed Windows app.

- **What an agent can do:** open a plan and describe it (floors, rooms and their areas, the plot), run the plan check against the plot's bylaws, work out the quantities, start a new plan with a plot, draw walls and rooms, place doors, windows and furniture, plan the ground floor from a room list, generate the structure, change or delete items, and export DXF, IFC and the structure schedule.
- **How to connect:** **Help › Connect AI agents…** shows the few lines to paste into Claude Desktop's settings (Settings › Developer › Edit Config), with a Copy button. Other agent apps that take MCP servers use the same lines. Nothing else needs installing.
- **It works on your plan files, on your computer.** You tell the agent the full path of a `.mimar` file. MIMAR itself sends nothing anywhere. If the plan is open in MIMAR while the agent changes it, open it again to see the changes.

The connector is in the app installed with the Setup file; the portable app and the web version don't have it.
